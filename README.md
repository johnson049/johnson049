## 🧠 About Me

<!-- Update your bio here -->
I'm an **Embedded Systems Engineer and IoT Developer** with an **M.Tech in Embedded Systems from NIELIT Calicut**. I enjoy building firmware and hardware-software systems on **ESP32, STM32, and Arduino**, from low-level drivers to cloud-connected devices.

Recently I've worked on a cross-technology configuration layer for Wi-Fi and BLE, a wireless 3-axis camera gimbal, and an IoT medicine reminder with a Flutter dashboard. I'm passionate about turning ideas into reliable, real-world embedded products.

- 🎓 **Education:** M.Tech in Embedded Systems (CGPA 8.21), NIELIT Calicut | B.Tech in ECE (CGPA 7.60), Sri Vasavi Engineering College
- 💼 **Current Role:** Embedded Systems Engineer | IoT Developer
- 🎯 **Career Goals:** Roles in embedded firmware development, IoT systems, and hardware-software integration, building microcontroller-based products and wireless connectivity (Wi-Fi, BLE), and growing into designing reliable, production-ready embedded systems.
- ❤️ **Interests:** Embedded Systems • IoT • Robotics • RTOS
- 🎉 **Fun Fact:** I built a wireless 3-axis camera gimbal from scratch using two ESP32s that talk to each other without any Wi-Fi router. 🌊

### 🌐 Cross-Technology Interface for IoT Connectivity Stack
> Designed a **Unified Configuration Abstraction Layer (UCAL)** for Wi-Fi and BLE, enabling host-side parameter configuration across different technology adapters. Includes firmware modules for profile generation, parameter management, packet encoding/decoding, and Protocol Buffer based serialization. Evaluated with PDR and RTT metrics in both simulation and hardware.

**Tech Stack:** `Embedded C` `Python` `Wi-Fi` `BLE` `Protocol Buffers` `Linux`

---

### 🎥 Wireless 3-Axis Camera Gimbal
> A wireless gimbal (yaw, pitch, roll) built with dual ESP32 boards for independent transmitter and receiver control. Uses **ESP-NOW** for low-latency, router-free communication, with ADC filtering for jitter-free servo response and PWM control for both positional and continuous-rotation servos. Powered by an 18650 Li-ion cell with TP4056 charging and protection.

**Tech Stack:** `ESP32` `ESP-NOW` `IoT` `Embedded C` `PCB Design`

[![GitHub Repo](https://img.shields.io/badge/View_Code-0077B6?style=for-the-badge&logo=github&logoColor=white)](https://github.com/johnson049/wireless-3-axis-camera-gimbal)

---

### 💊 Smart Medicine Reminder and Monitoring System
> An IoT medicine reminder using ESP32 with RTC-based scheduling, multi-alarm support, snooze, weekday selection, EEPROM storage, and reed-sensor pill-intake detection. Adherence logs sync to **Supabase**, with REST APIs and a **Flutter dashboard** to visualize medication history and device status.

**Tech Stack:** `ESP32` `DS3231 RTC` `IoT` `Supabase` `Flutter`
